Text File Database

User profiles and dashboard entries are saved directly in local text files (data/*.txt) using newline-delimited JSON. Thread concurrency is protected via ReentrantReadWriteLock.

Session & Hash Auth

Passwords are salted and cryptographically hashed with SHA-256 before writing to disk. Unauthenticated requests to protected endpoints are guarded with custom Spring MVC interceptors.

Future Docker Integration

When you're ready to integrate Docker in the final step, simply map the ./data directory to a Docker volume (-v /host/data:/app/data) to preserve your data permanently across container rebuilds!
